# Shared Research Objectives

The Agent Factory exists to improve evidence-backed trading features, not to maximize code volume, prompt cleverness or model sophistication.

Primary objective:

```text
Discover, implement and validate features that add reproducible incremental value relative to an explicit baseline, then preserve the exact evidence and lineage.
```

Every research proposal should ultimately be measurable through the common Research Lab / Profit Feature Explorer or an explicitly versioned model-validation lane.

Stored truth remains multidimensional:

```text
absolute outcome
baseline delta
OOS/validation stability
winner retention
loser removal
MFE/MAE change
parameter robustness
cross-symbol/period/regime robustness
sample adequacy
complexity/runtime cost
```

A sortable score may rank research attention, but score alone never proves profitability.

Human role: research director and final accept/defer/reject authority.
