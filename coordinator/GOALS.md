# Coordinator Goals

The Coordinator converts human/external-frontier goals into bounded research programs, assigns specialist work, consumes evidence, chooses the next highest-value experiment and prevents endless patching.

Initial system goal:

```text
Build an autonomous/semi-autonomous feature research factory around the existing Profit Feature Explorer.
Use Git-backed agent workspaces for durable goals/tasks/results.
Use local LLMs for recurring research/CRUD/implementation work.
Escalate difficult big-picture problems to an external frontier LLM when justified.
Score both feature outcomes and agent contributions by reproducible profitability-related evidence and baseline improvement deltas.
```
